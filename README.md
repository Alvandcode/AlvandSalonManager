# Alvand Salon Manager | مدیریت آرایشگاه الوند

اپلیکیشن اندرویدی فارسی برای مدیریت خدمات، درآمد، هزینه‌ها و مشتریان با ذخیره‌سازی محلی SQLite.

## قابلیت‌ها
- فهرست خدمات به سبک کاتالوگ: افزودن، ویرایش و حذف خدمت، قیمت و توضیحات
- ذخیره دائمی خدمات در پایگاه داده محلی
- ثبت درآمدهای انجام‌شده و هزینه‌ها با تاریخ شمسی
- ثبت اطلاعات مشتریان
- گزارش درآمد روزانه، هفتگی، ماهانه و سالانه
- رابط فارسی و راست‌چین با تم تیره و رنگ طلایی
- صفحه «درباره» و لینک قابل کلیک پروفایل سازنده
- نام‌گذاری فایل‌های خروجی با نام پروژه و نسخه
- ساخت APK و انتشار GitHub Release به‌صورت خودکار پس از push به شاخه `main`

## سازنده
GitHub: https://github.com/Alvandcode/
مخزن: https://github.com/Alvandcode/AlvandSalonManager

## انتشار خودکار
Workflow در `.github/workflows/android.yml` قرار دارد. با push به `main` یا اجرای دستی workflow، برنامه ساخته می‌شود، APK نسخه‌دار به‌عنوان artifact بارگذاری می‌شود و GitHub Release همراه با فایل‌ها ایجاد می‌شود. مجوز `contents: write` برای ساخت Release لازم است.

الگوی نام APK: `AlvandSalonManager-v<version>-Android.apk`

نسخه پایه در `app/build.gradle.kts` با `versionName` و `versionCode` مشخص می‌شود؛ شماره اجرای GitHub Actions به نسخه Release اضافه می‌شود تا انتشارهای متوالی تگ یکتا داشته باشند.

## ساخت محلی
با Android SDK و JDK 17 نصب‌شده، از ریشه پروژه اجرا کنید:

```bash
gradle assembleDebug
```

خروجی APK در `app/build/outputs/apk/debug/` قرار می‌گیرد.

## نکته داده‌ها
اطلاعات روی همان دستگاه و در SQLite ذخیره می‌شوند. برای جلوگیری از ازدست‌رفتن داده‌ها، در حال حاضر از اطلاعات مهم نسخه پشتیبان تهیه کنید.
