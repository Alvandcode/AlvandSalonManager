# Alvand Salon Manager | مدیریت مالی آرایشگاه

اپلیکیشن اندرویدی مدیریت خدمات، درآمد، هزینه‌ها و مشتریان با رابط فارسی و تقویم هجری شمسی.

## امکانات نسخه اولیه
- سازگار با Android 9 تا 15 (حداقل API 28)
- ثبت خدمات انجام‌شده، مبلغ و تاریخ شمسی
- ثبت هزینه‌ها
- ثبت نام و شماره تماس مشتری
- محاسبه درآمد خالص روزانه، هفتگی، ماهانه و سالانه
- تم روشن و تیره
- ذخیره محلی داده‌ها با SQLite؛ بدون نیاز به اینترنت یا حساب کاربری
- طراحی فارسی راست‌چین

## ساخت APK
1. پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle همگام‌سازی شود.
3. از منوی **Build > Build APK(s)** خروجی بگیرید.
4. فایل APK معمولاً در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## انتشار در GitHub
کل محتویات این پوشه را در یک مخزن GitHub بارگذاری کنید. برای ساخت خودکار APK می‌توانید از workflow موجود در `.github/workflows/android.yml` استفاده کنید.

## نکته
این نسخه، پایه‌ی قابل توسعه‌ی پروژه است. پیش از استفاده برای حسابداری واقعی، از داده‌ها نسخه پشتیبان تهیه کنید؛ قابلیت خروجی/بازیابی فایل در این نسخه هنوز پیاده‌سازی نشده است.
